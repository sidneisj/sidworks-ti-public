# Fontes usadas nos relatórios

Este repositório inclui somente os três arquivos DejaVu necessários à geração dos PDFs:
`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` e `DejaVuSans-Oblique.ttf`.

A licença original da família DejaVu está reproduzida em `LICENSE-DejaVu.txt`.
Estas fontes são componentes de terceiros, com licença independente da licença do código SidWorks TI.
